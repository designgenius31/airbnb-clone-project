# Airbnb Clone Project

## Overview
This project is a full-stack clone of the popular booking platform **Airbnb**.  
It allows users to browse listings, view details, and make bookings.

## Project Goals
- Build a responsive and interactive web app
- Learn how frontend and backend work together
- Practice teamwork and good documentation

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript (React)
- **Version Control:** Git & GitHub
- **Design Tool:** Figma

## UI/UX Design Planning

### Design Goals
- Easy and smooth booking process  
- Consistent look across all pages  
- Fast loading pages  
- Works well on mobile and desktop

### Key Features
- Property search and filters  
- Detailed property view with photos  
- Simple and secure booking process  
- User login and sign-up

### Primary Pages

| Page | Description |
| **Property Listing View** | Shows all available properties in a grid with filters |
| **Listing Detailed View** | Displays property details, photos, and booking form |
| **Simple Checkout View** | Allows users to confirm and pay for bookings |

### Why User-Friendly Design Matters
A good design helps users find what they need faster, keeps them happy, and makes them trust the site more.  
Simple navigation and a clean layout improve user experience.

### Figma Design Specifications

#### Colors
- **Primary:** #FF5A5F  
- **Secondary:** #008489  
- **Background:** #FFFFFF  
- **Text:** #222222  
- **Secondary Text:** #717171  

#### Typography (Fonts)
- **Main Font:** Circular  
- **Headings:** Bold (700), 24–32px  
- **Body Text:** Medium (500), 16px  
- **Small Text:** Book (400), 14px  

#### Why This is Important
Knowing the colors and fonts before starting makes the app look professional and consistent.  
It also helps everyone on the team follow the same design style.

## Project Roles and Responsibilities

| Role | Responsibilities |
| **Project Manager** | Keeps the project on schedule and organized |
| **Frontend Developers** | Build the user interface and ensure it works on all devices |
| **Backend Developers** | Create APIs, manage data, and handle logic |
| **Designers** | Design the mockups and ensure good user experience |
| **QA/Testers** | Test the site and report bugs |
| **DevOps Engineers** | Deploy and manage servers |
| **Product Owner** | Defines features and priorities |
| **Scrum Master** | Runs meetings and helps remove blockers |

## UI Component Patterns
#### Navbar
- Has the logo, search bar, and user menu
- Works on both desktop and mobile

#### Property Card
- Shows property image, name, location, price, and rating
- Has a favorite (heart) button

#### Footer
- Has site links, company info, and social media icons
- Same across all pages

Each component will be reusable and built with a consistent style.
